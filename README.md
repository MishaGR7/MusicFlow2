#  MusicFlow (Music Release Monitor)

A web-based platform designed to track new music releases, manage favorite artists, and discover new albums. This project features a robust system for music enthusiasts to stay updated with their favorite creators.

Project Theme: Web platform for announcing releases of musical groups and artists.

## ✨ Key Features

*   **Search Engine:** Find artists, albums, and specific releases within the database.
*   **Personal Favorites:** Users can follow artists to curate a personalized feed of updates.
*   **User & Admin Roles:** Integrated authentication with specific dashboards for general users and administrators.
*   **Music Management:** Full CRUD operations for managing artists and release information.
*   **Responsive Interface:** A clean, modern UI optimized for both desktop and mobile viewing.

## 🛠 Tech Stack

*   **Framework:** Laravel (PHP 8.x)
*   **Database:** SQLite
*   **Frontend:** React, Inertia.js, Tailwind CSS, Vite
*   **Tools:** Composer, NPM, Git

## 🚀 Quick Start

1. Clone the repository and install dependencies using `composer install` and `npm install`.
2. Configure your `.env` file to use the `sqlite` database driver.
3. Run `php artisan migrate` to set up the database schema.
4. Launch the application with `php artisan serve`.
